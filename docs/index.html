论文机制

Regime

Causal HMM

只做前向过滤的状态概率；避免使用完整路径 Viterbi 造成在线前视。

Transition

EWS + BOCPD

方差、自相关、偏度与贝叶斯在线变点概率，用于状态转换风险而非直接预测涨跌。

Dynamics

Koopman / DMD

固定过去窗口拟合线性动力算子，输出无法被局部动力学解释的残差。

Bubble feasibility

Classic LPPLS

固定参数网格，报告拟合残差与 tc 分布稳定性，不发布单一“神奇崩盘日”。

Shrinkage

Black–Litterman

把嘈杂观点收缩到先验；改善观点融合，但不凭空创造信息。

Labels & exits

Triple Barrier

止盈、止损、时间三重离线标签。标签明确使用未来，因此禁止进入特征。

Tail evidence

Hoeffding Bound

对有限样本胜率给出保守下界；同时提醒依赖性与有效样本量问题。

Selection bias

PBO + Deflated Sharpe

把尝试次数和候选间选择折算进证据门槛，拒绝“最好看的那条曲线”。
